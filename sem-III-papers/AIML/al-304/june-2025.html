Grading System (GS) / Working Professional

Note:
i) Attempt any five questions.

iii) Assume any missing data.

Previous Year Questions (June 2025)

Q.1

a) What is production system? Explain it with an example. Discuss the characteristics of a production system. (Unit 1)

b) Give an example of a problem for which breadth first search would work better than depth first search. (Unit 1)
Q.2

a) Discuss various approaches and issues in knowledge representation. Also discuss various problems in representing knowledge. (Unit 2)

b) Consider the following statements and use predicate logic to express them formally: (Unit 2)

  • Marcus tried to assassinate Caesar.
  • All Pompeian's were Roman.
  • All Romans were either loyal to Caesar or hated him.
  • Everyone is loyal to someone.
  • People only try to assassinate rulers they are not loyal to.
Q.3

a) Design a simple knowledge base using semantic networks for a weather prediction system. (Unit 3)

b) Define Baye's theorem. What are the applications of Bayes theorem? (Unit 3)
Q.4

a) What is the Block World problem in AI planning? Explain with an example. (Unit 4)

b) Develop a simple AI-based chatbot using rule-based NLP. (Unit 4)
Q.5

a) Describe the architecture and working of an expert system. (Unit 5)

b) Design a rule-based expert system for diagnosing diseases. (Unit 5)

Write short notes on (any two) (Unit 5)
