B.Tech. I & II Semester
Examination, December 2023
Grading System (GS)
Max Marks: 70 | Time: 3 Hours

Note:
i) Attempt any five questions.
ii) All questions carry equal marks.

Previous Year Questions (December 2023)

Q.1

a) State Lagrange's theorem hence verify for $f(x)=x^2+2x$ defined in the interval [-2, 0]. (Unit 1)

b) Find the first six terms of the expansions of the function $e^x\cos y$ in a Taylor series in the neighbourhood of the point (0, 0). (Unit 1)
Q.2

a) Estimate the extreme values of the function $x^3+y^3-63(x+y)+12xy$. (Unit 1)

b) If $u=\left(\frac{y-x}{xy}\right)\left(\frac{z-x}{xz}\right)$ find the value of $x^2u_x+y^2u_y+z^2u_z$. (Unit 1)
Q.3

a) Show that the rectangular solid of maximum volume that can be inscribed in a given sphere is a cube. (Unit 1)

b) Find $\frac{du}{dt}$ if $u=x^2+y^2, x=a\cos t, y=b\sin t$. (Unit 1)
Q.4

a) Change the order of integration in $\int_{0}^{1}\int_{x^2}^{2-x}xy\ dy\ dx$ and hence evaluate. (Unit 2)

b) i) Find the value of $\Gamma(\frac{3}{2})$. (Unit 2)

ii) Evaluate $\int_{0}^{1}x^3(1-\sqrt{x})^2dx$. (Unit 2)
