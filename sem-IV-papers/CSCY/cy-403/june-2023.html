CY-403 (GS) – Computer Networks

B.Tech. IV Semester
Examination, June 2023
Grading System (GS)
Max Marks: 70 | Time: 3 Hours

Note:
i) Attempt any five questions.
ii) All questions carry equal marks.

Previous Year Questions (June 2023)

Q.1

a) Draw the ISO-OSI architecture and outline the function performed by each layer. (Unit 1)

b) Compare and contrast guided and unguided media for transmission. (Unit 1)
Q.2

a) List out the functions of the Data Link Layer. One channel with a bit rate of 190 kbps and another with a bit rate of 180 kbps are to be multiplexed using TDM with no synchronization bits.
i) What is the size of a frame in bits?
ii) What is the data rate? (Unit 2)

b) Define the relationship between transmission delay and propagation delay, if the efficiency is at least 50% in STOP N WAIT protocol. (Unit 2)
Q.3

a) Differentiate between Virtual Circuit versus Datagram Subnets. (Unit 3)

b) The IP network 200.198.160.0 is using subnet mask 255.255.255.224. Design the subnets. (Unit 5)
Q.4

a) Explain Distance Vector Routing (DVR) with working example in detail. (Unit 4)

b) Discuss in detail about ICMP role in network layer. (Unit 4)
Q.5

a) What is the format of an Email? Explain the architecture of a mailing system. (Unit 5)

b) Provide few reasons for congestion in a network. What is the purpose of the Domain Name System? (Unit 5)
Q.6

a) Explain network topological design with necessary diagram and brief the advantages and disadvantages of various topologies. (Unit 1)

b) Discuss the issues in the data link layer and about its protocol on the basis of layering principle. (Unit 2)
Q.7

a) Assume we want to send a data from S to R and there are 2 routers in between. What will be the total time taken if total number of packets is 5? Data is like:
$Tp=0$ ms, Data size $=1000$ bytes, $BW=1$ mbps, Header of the packet $=100$ bytes. (Unit 2)

b) Explain CSMA/CD in detail. (Unit 2)
Q.8

Write Technical short note on any two:

i) Introduction to ISDN (Unit 1)

ii) HDLC (Unit 2)

iii) HUB (Unit 3)

iv) Jitter control (Unit 5)
