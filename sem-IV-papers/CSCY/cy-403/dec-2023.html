CY-403 (GS) – Computer Networks

B.Tech. IV Semester
Examination, November 2023
Grading System (GS)
Max Marks: 70 | Time: 3 Hours

Note:
i) Attempt any five questions.
ii) All questions carry equal marks.

Previous Year Questions (November 2023)

Q.1

a) Difference between server based and Peer to Peer Networking. (Unit 1)

b) Explain the term Nyquist bit rate and Shannon capacity. (Unit 1)
Q.2

a) Explain MAC along with working of all CSMA protocols. (Unit 2)

b) What is the purpose of Hamming code? Construct Hamming code for the bit sequence 10011101. (Unit 2)
Q.3

a) Explain the working of IEEE 802.4 standard. Also explain the working of Frame format. (Unit 3)

b) Imagine the length of ring in token ring is 1000 meter if the speed of propagation in a twisted pair cables is 60 percent of the speed of light (300,000,000 meter/ second). How long does it takes for a bit to make a complete trip? (Unit 3)
Q.4

a) Explain any two unicast static and dynamic routing Algorithms. (Unit 4)

b) Describe subnet mask. Explain different classes of IP address. (Unit 4)
Q.5

a) Explain the various congestion control Algorithms. (Unit 5)

b) Explain the addressing using DNS. (Unit 5)
Q.6

a) Explain OSI model stating its importance in network architecture. (Unit 1)

b) What is the principle difference between connectionless and connection oriented communication. (Unit 5)
Q.7

a) Discuss internet services standards for TCP/IP and the process of standardization for RFCS and TCP/IP. (Unit 4)

b) Explain distance vector routing with example. (Unit 4)
Q.8

Describe Frame Relay Protocol architecture and explain the function of each one. (Unit 2)
