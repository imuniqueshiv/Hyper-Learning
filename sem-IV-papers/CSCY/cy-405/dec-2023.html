CY-405 (GS) – Database Management System

B.Tech., IV Semester
Examination, November 2023
Grading System (GS)
Max Marks: 70 | Time: 3 Hours

Note:
i) Attempt any five questions.
ii) All questions carry equal marks.

Previous Year Questions (November 2023)

Q.1

a) Explain the architecture of Database Management Systems with neat diagram? (Unit 1)

b) What is Null Attribute? With suitable diagram explain Weak and Strong Entity Set. (Unit 1)
Q.2

a) Discuss about File Organization and Access methods. (Unit 1)

b) How to write the queries in Relational Algebra? Explain with examples. (Unit 2)
Q.3

a) What do you understand by Tuples and Attributes? Explain with examples. (Unit 2)

b) Discuss about Joins with suitable examples. (Unit 2)
Q.4

a) Explain normalization using (1NF, 2NF, 4NF) with suitable examples? (Unit 3)

b) What are the steps to be followed to convert a relation in 3NF to BCNF? (Unit 3)
Q.5

a) Compute the closer of the following set of functional dependencies for a relation scheme.
R(A, B, C, D, E), $F=\{A\rightarrow BC, CD\rightarrow E, B\rightarrow D, E\rightarrow A\}$
List out the candidate keys of R. (Unit 3)

b) State and explain shadow paging with suitable example. (Unit 4)
Q.6

a) Discuss about Timestamp Based Concurring Control. (Unit 4)

b) What do you understand by Deadlocks, Explain Avoidance and Prevention in deadlock? (Unit 4)
Q.7

a) Write an algorithm to implement project and join operation of relational Algebra. (Unit 5)

b) Compare Single and Multilevel indices. (Unit 5)
Q.8

Write short notes on any two:

i) Complexity Measures (Unit 5)

ii) Components of DBMS (Unit 1)

iii) Triggers (Unit 2)

iv) Recoverability (Unit 4)
