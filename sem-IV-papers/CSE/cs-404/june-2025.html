AL/CSIT (CI)/CS/CT/CO/IO/IS-404 (GS) – Computer Organization & Architecture

B.Tech./B.Tech. (Working Professional) IV Semester
Examination, June 2025
Grading System (GS) / Working Professional
Max Marks: 70 | Time: 3 Hours

Note:
i) Attempt any five questions.
ii) All questions carry equal marks.

Previous Year Questions (June 2025)

Q.1

a) Discuss the structure and role of the program counter, instruction register and memory register during a fetch-execute cycle. (Unit 2)

b) How does the control word help in micro-operation execution? Illustrate with an example. (Unit 1)
Q.2

a) Illustrate the concept of bus structure. How does it aid in CPU and memory communication? (Unit 1)

b) Explain 1's and 2's complement representation for negative numbers with examples. (Unit 3)
Q.3

a) Describe Booth's algorithm for multiplication. Illustrate with a 4-bit example. (Unit 3)

b) Compare fixed point and floating point arithmetic operations with examples. (Unit 3)
Q.4

a) How does USB differ from SCSI bus in terms of speed, cost and application? (Unit 4)

b) Write a comparative note on different types of I/O interfaces. (Unit 4)
Q.5

a) Explain the working of PCI bus. How does it improve I/O performance? (Unit 4)

b) Differentiate magnetic tape, disk and optical storage based on access time, reliability and cost. (Unit 5)
Q.6

a) How does cache memory improve system performance? Explain cache design. (Unit 5)

b) Write a program in Pseudo code to simulate page replacement using LRU. (Unit 5)
Q.7

a) Describe the structure and working of inter-processor communication and synchronization. (Unit 5)

b) Compare RISC and CISC architectures with examples. (Unit 5)
Q.8

Write a short note on any two from the following.

a) Direct Memory Access (Unit 4)

b) Virtual Memory (Unit 5)

c) Read Only Memory (Unit 5)
