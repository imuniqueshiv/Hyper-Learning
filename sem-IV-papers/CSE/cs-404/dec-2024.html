AL/CSIT (CI)/CS/CT/CO/IO/IS-404 (GS) – Computer Organization & Architecture

B.Tech. IV Semester
Examination, December 2024
Grading System (GS)
Max Marks: 70 | Time: 3 Hours

Note:
i) Attempt any five questions.
ii) All questions carry equal marks.

Previous Year Questions (December 2024)

Q.1

a) Differentiate between accumulator, index, stack and general-purpose registers in terms of their functions and usage. (Unit 1)

b) Discuss the sequence of steps involved in fetching an instruction from memory and executing it. (Unit 2)
Q.2

a) Describe how micro instructions are arranged in control memory and how they are interpreted? (Unit 2)

b) Draw the flowchart for Booth's algorithm for multiplication of signed 2's complement numbers and explain with an example? (Unit 3)
Q.3

a) Describe the basic arithmetic operations supported by floating-point arithmetic, including addition, subtraction, multiplication and division. (Unit 3)

b) What components are required to design the arithmetic unit explain with neat sketch? (Unit 3)
Q.4

a) Discuss the fundamental differences between serial and parallel data transfer methods in terms of data transmission, speed and implementation complexity. (Unit 4)

b) What is direct memory transfer? Give an overview and block diagram of a DMA controller? (Unit 4)
Q.5

a) Differentiate synchronous and asynchronous data transfer? (Unit 4)

b) Explain the concept of memory hierarchy and its significance in modern computer systems. (Unit 5)
Q.6

a) Compare and contrast different cache mapping techniques, including direct mapping, set-associative mapping and fully associative mapping. Discuss the advantages and disadvantages of each mapping technique. (Unit 5)

b) Explain the concept of memory segmentation and how it complements virtual memory. Discuss the advantages and challenges of using segmentation in memory management. (Unit 5)
Q.7

a) Describe different types of interconnection networks used in multiprocessor systems. (Unit 6)

b) Define array processing and explain its significance in computer architecture and parallel computing. (Unit 6)
Q.8

Write a short note on any two of the following:

a) Instruction types (Unit 2)

b) PCI Bus (Unit 4)

c) Read Only Memory (Unit 5)

d) Inter-processor communication and synchronization (Unit 6)
