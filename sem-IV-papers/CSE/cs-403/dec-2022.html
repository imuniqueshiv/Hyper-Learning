AL/CD/CS/CT/CO-403 (GS) – Software Engineering

B.Tech. IV Semester
Examination, November 2022
Grading System (GS)
Max Marks: 70 | Time: 3 Hours

Note:
i) Answer any five questions.
ii) All questions carry equal marks.

Previous Year Questions (November 2022)

Q.1

a) With a neat diagram explain about the component assembly model and rational unified process. (Unit 1)

b) Write about the characteristics of software engineering. (Unit 1)
Q.2

a) Explain about the CMM levels. (Unit 1)

b) Draw a use case diagram for booking a ticket in a reservation system. (Unit 2)
Q.3

a) What is meant by software requirement elicitation. How the requirements can be specified. (Unit 2)

b) What is a model? Why it is needed in the development of software. (Unit 3)
Q.4

a) Explain in detail about the design concepts and principles. (Unit 3)

b) How architecture is used in the development of software. What are the different styles used for it? Explain any two of them. (Unit 3)
Q.5

a) How do you describe the architecture of the software intensive system based on the use of multiple, concurrent views. (Unit 3)

b) Explain different specialized testing techniques. (Unit 4)
Q.6

a) What is the need of integration testing? Explain it with a neat figure. (Unit 4)

b) What is software testing? What are the levels present in it? How unit testing is used for software. (Unit 4)
Q.7

a) Explain software configuration management in detail. (Unit 5)

b) Write the difference between the re-engineering and reverse engineering with diagrams. (Unit 5)
Q.8

Write short notes on:

a) Traceability (Unit 2)

b) Static Analysis (Unit 4)

c) Risk management (Unit 5)
